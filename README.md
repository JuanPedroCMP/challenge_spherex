# Planet X and SPHEREx (NASA Space Apps 2026, Challenge 12)

A public web tool that shows how the sky changes in NASA SPHEREx images: enter a sky position (RA/Dec) and watch a short flipbook of that patch across SPHEREx visits, to spot moving objects such as brown dwarfs, asteroids and comets.

Built with NASA data. Work in progress during the hackathon (Nov 14-15, 2026).
